Give web AI hands on your computer.

Chat with a free web AI — like Muse's free tier — and tell it what you
want done on YOUR computer. The AI writes a command, webai-hands runs it
locally, and the result comes back into the chat. No copy-pasting, no
switching windows, no paid API keys.

WHAT IT DOES
- Turn chat into action: organize files, search your disk, run git, and more —
  just by talking.
- Send files to the AI: ask it to read a PDF or summarize a document straight
  from your machine, as a real chat attachment.
- Drive desktop apps: verified with Blender — describe the 3D scene you want
  and watch it appear.

HOW IT WORKS
This extension is the browser half of webai-hands. It also needs the free,
open-source local program (one install, ~5 minutes):
  1. Install this extension.
  2. Install the local host from the project page
     (github.com/Achillesy/Python-webai-hands).
  3. Paste the short AI-GUIDE into your AI chat and start talking.

PRIVACY & SECURITY
- The local program opens no network ports and talks only to this extension.
- It never sees, stores, or types your passwords; admin actions pop a system
  dialog for you to approve.
- Sensitive files (SSH keys, browser cookies, .env, …) are refused; uploads
  are capped at 25MB.
- This extension collects no data and shows no ads.
